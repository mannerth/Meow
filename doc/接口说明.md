1. 概述 (Overview)
本此文档定义了 SDU Meow 项目的前后端交互接口。遵循 RESTful 风格，所有数据传输采用 JSON 格式。
1.1 基础信息
• Base URL: ``
• Protocol: HTTPS
• Date Format: ISO 8601 (YYYY-MM-DDTHH:mm:ssZ)
1.2 鉴权 (Authentication)
所有受保护的接口需要在 Header 中携带 Bearer Token。
Authorization: Bearer <your_jwt_token>1.3 统一响应结构 (Response Structure)
{
  "code": 200,          // 业务状态码：200成功，非200失败
  "message": "success", // 提示信息
  "data": { ... }       // 业务数据
}1.4 业务状态码
• 200: 成功
• 401: 未登录/Token过期
• 403: 权限不足 (如普通用户访问管理员接口)
• 404: 资源不存在
• 422: 参数校验错误
• 500: 服务器内部错误

}3. 猫咪档案模块 (Cat Profile)
3.1 获取猫咪列表 (List Cats)
支持分页、筛选、搜索。
• URL: /cats
• Method: GET
• Headers: Authorization: Bearer <token> (可选，未登录可浏览)
• Query Params:
    ◦ page: int (default 1)
    ◦ pageSize: int (default 20)
    ◦ campus: string (校区筛选，e.g., "SOFTWARE_PARK", "CENTRAL", "ALL")
    ◦ status: string (状态筛选，e.g., "SCHOOL" 在校, "GRADUATED" 毕业, "MEOW_STAR" 喵星, "HOSPITAL" 住院)
    ◦ color: string (花色筛选，如 "橘猫", "三花", "奶牛")
    ◦ search: string (搜索名字)
    ◦ sort: string (排序筛选（逆序），e.g., "popularity" 人气, "createTime" 发现时间, "lastSeenTime" 最后出现时间)
• Response:
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100, // 总记录数
    "items": [ // 列表项
      {
        "id": "c001", // 猫咪ID
        "name": "麻薯", // 名字
        "avatar": "https://...", // 头像
        "color": "三花", // 花色

        "popularity": 1204, // 人气值
